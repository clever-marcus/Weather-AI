# WeatherAI API Test Automation Framework

A comprehensive test automation framework for testing the WeatherAI MCP API.

## 🚀 Features

- Full API testing coverage for weather endpoints
- Happy path and edge case validation
- Automated test reporting with HTML reports
- CI/CD integration with GitHub Actions
- Environment-based configuration
- Clear test structure with pytest

## 📋 Prerequisites

- Python 3.8+
- WeatherAI API Key (Get free from https://weatherai.io)
